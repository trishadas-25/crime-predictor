## Project Overview

This project predicts probable crime patterns using Machine Learning and visualizes geographic crime hotspots through an interactive India heatmap.

Features:

- Crime Prediction
- India Heatmap
- Risk Analysis
- Safety Suggestions
- Interactive Dashboard

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Folium
- Pandas
- Geopy
